# Шаблон проекта

- *client-template* - пример веб-приложения без сервера (только фронтенд). Используется localStorage для хранения данных. Приложение с кликером и задачами.
- *node-template* - пример веб-приложения с сервером node.js (sqlite, express, статический фронтенд). Приложение с задачами, заметками и журналом настроения.
- *blank-template* - пустой шаблон веб-приложения с сервером node.js, есть всё необходимое. Сначала лучше ознакомиться с *node-template*.
