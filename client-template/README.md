# Altair — клиентский шаблон

Небольшое многостраничное приложение без Node.js, сервера и сборщиков.
Все данные хранятся в `localStorage` браузера.

Страницы:

- `index.html` — главная страница с количеством невыполненных задач и нажатий;
- `clicker.html` — счётчик нажатий с сердечком;
- `todo.html` — список задач с добавлением, отметкой «выполнено» и удалением.

## Дерево файлов

```text
client-template/
├── index.html              главная страница (dashboard)
├── clicker.html            страница счётчика
├── todo.html               страница задач
├── README.md               этот файл
└── assets/
    ├── css/
    │   ├── colors.css      цвета проекта в CSS-переменных
    │   └── main.css        общие стили всех страниц
    ├── js/
    │   ├── clicker.js      логика счётчика
    │   ├── dashboard.js    подсчёт невыполненных задач и нажатий
    │   ├── todo-storage.js общая работа с задачами в localStorage
    │   └── todo.js         добавление, выполнение и удаление задач
    ├── img/                пустая папка для будущих изображений
    └── icons/
        └── heart.svg       иконка сердечка
```

Навигация между страницами сделана обычными ссылками. Активная страница
выделена в шапке.

## Запуск

Node.js не требуется.

1. Откройте `client-template/index.html` в браузере.
2. Переходите между разделами через меню в шапке.
3. Добавьте несколько задач и отметьте часть выполненными.
4. Нажмите на сердечко на странице счётчика.
5. Вернитесь на главную — там отобразятся количество невыполненных задач
   и количество нажатий.

Если браузер ограничивает `localStorage` при открытии через `file://`,
запустите любой статический сервер. Например, Live Server в Visual Studio Code.

## Как хранятся данные

Приложение использует два независимых ключа `localStorage`.

### Задачи

Ключ:

```text
altair.todo.v1
```

Формат значения:

```json
{
  "tasks": [
    { "id": "1762430000000", "text": "Подготовить макет", "done": false }
  ]
}
```

- задачи читает и сохраняет `assets/js/todo-storage.js`;
- `todo.js` добавляет, отмечает и удаляет задачи;
- `dashboard.js` читает тот же ключ и считает задачи с `done: false`.

### Счётчик нажатий

Ключ:

```text
altair.clicker.v1
```

Формат значения:

```json
{ "clicks": 2 }
```

Счётчик сохраняется при каждом нажатии и восстанавливается после перезагрузки.
Кнопка «Сбросить» сохраняет значение `0`. Главная страница читает этот же ключ
и показывает количество нажатий во второй карточке.

Посмотреть данные можно в инструментах разработчика браузера:
**Application → Local Storage** (в Firefox — **Storage → Local Storage**).

## Как расширять шаблон

### Новая страница

1. Создайте HTML-файл по образцу `todo.html`.
2. Скопируйте шапку и отметьте активную вкладку.
3. Добавьте ссылку на страницу в меню всех HTML-файлов.
4. Подключите общий CSS и отдельный JS-файл.

### Новые данные

Если данные относятся к задачам, добавьте поле в объект задачи
в `todo.js` и обработайте его в `todo-storage.js`.

Для отдельной сущности создайте новый ключ, например
`altair.notes.v1`, и функции чтения/записи по образцу
`todo-storage.js`.

## Принципы шаблона

- никаких библиотек, фреймворков и сборщиков;
- никакого Node.js и сервера;
- простая HTML-структура;
- по одному JS-файлу на страницу плюс общий модуль хранения;
- цвета вынесены в `assets/css/colors.css`;
- все данные сохраняются в `localStorage`;
- комментарии и интерфейс на русском языке.
